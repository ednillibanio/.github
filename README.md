# .github

Default community health files for repositories owned by `ednillibanio`.

GitHub uses these files for any repository in this account that does not have its own copy:

- `.github/ISSUE_TEMPLATE/`: issue forms (bug, enhancement, iteration, standard);
- `.github/PULL_REQUEST_TEMPLATE.md`: pull request template.

A repository overrides a default by adding its own file at the same path.

Adapted from the `assembleiarr/.github` templates.
